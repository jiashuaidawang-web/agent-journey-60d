# Day 28 Boss 答案

## 1. Supervisor 模式的流程？

```
1. Supervisor 接收任务
2. 分析任务，决定分配给哪个 Worker
3. Worker 执行任务
4. Worker 返回结果
5. Supervisor 汇总结果
6. 返回最终结果
```

## 2. 如何分配任务？

**分配策略**：
1. **能力匹配**：根据 Worker 的能力分配
2. **负载均衡**：选择空闲的 Worker
3. **优先级**：高优先级任务优先分配
4. **依赖**：有依赖的任务按顺序分配

## 3. 如何处理 Worker 失败？

**处理策略**：
1. **重试**：重新分配给同一个 Worker
2. **转移**：分配给其他 Worker
3. **降级**：返回部分结果
4. **告警**：通知管理员
