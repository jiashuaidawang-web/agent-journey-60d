# 学习执行规范

## 每日最低标准

如果当天时间只有1小时：

1. 20分钟理论
2. 30分钟编码
3. 10分钟总结

如果当天有3小时：

1. 30分钟理论
2. 30分钟官方文档/源码
3. 90分钟编码
4. 20分钟实验
5. 10分钟Git

## 学习记录模板

```markdown
# Day XX
```
