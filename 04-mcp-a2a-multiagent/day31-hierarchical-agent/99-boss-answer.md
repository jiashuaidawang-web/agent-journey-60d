# Day 31 Boss 答案

## 1. 层级 Agent 的流程？

```
1. Top Manager 接收复杂任务
2. 分解任务，分配给中层 Manager
3. 中层 Manager 分配给底层 Worker
4. Worker 执行任务
5. 中层 Manager 汇总结果
6. Top Manager 汇总最终结果
```

## 2. 什么时候用层级结构？

- **复杂任务**：需要多层分解
- **大规模协作**：多个团队/部门
- **需要管理**：需要分层监督
- **职责清晰**：每层职责明确

## 3. 层级过多有什么问题？

1. **延迟增加**：每层都有通信开销
2. **信息衰减**：层级越多，信息传递越失真
3. **复杂度增加**：管理成本上升
4. **调试困难**：问题定位困难

**建议**：不超过 3 层
