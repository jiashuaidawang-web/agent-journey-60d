# Day 42 Boss 答案

## 1. 评测流水线的流程？

```
1. 数据集加载
   - 加载评测数据集（问题、标准答案、相关文档）
   ↓
2. RAG 执行
   - 对每个问题执行 RAG
   - 生成回答和检索上下文
   ↓
3. 指标计算
   - 计算各评测指标
   - 生成评分
   ↓
4. 报告生成
   - 汇总结果
   - 生成评测报告
   ↓
5. 结果存储
   - 存储评测结果
   - 对比历史结果
```

## 2. 如何自动化评测？

1. **定期运行**：每天/每周自动评测
2. **CI/CD 集成**：代码变更后自动评测
3. **告警机制**：指标退化时告警
4. **趋势分析**：对比历史结果

## 3. 如何发现 RAG 退化？

1. **监控指标**：持续监控各指标
2. **对比基线**：与历史基线对比
3. **设置阈值**：低于阈值告警
4. **根因分析**：分析退化原因
