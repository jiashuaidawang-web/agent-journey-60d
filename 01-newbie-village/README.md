## Java → Python 快速对照

| 概念 | Java | Python |
|------|------|--------|
| 接口 | `interface` | `Protocol` / `ABC` |
| 数据类 | `DTO + Lombok` | `dataclass` / `Pydantic` |
| 异步 | `CompletableFuture` | `asyncio` / `await` |
| 泛型 | `List<T>` | `list[T]` |
| 注解 | `@Override` | `@dataclass` / `@property` |
| Stream | `stream().map()` | generator / `yield` |
