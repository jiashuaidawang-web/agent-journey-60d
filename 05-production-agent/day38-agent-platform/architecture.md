## 核心模块说明

### 1. Agent Gateway

| 功能 | 说明 |
|------|------|
| 路由 | 请求路由到对应 Agent |
| 限流 | 租户级限流 |
| 认证 | API Key / JWT 认证 |
| 日志 | 请求日志 |

### 2. Java Control Plane

| 模块 | 职责 |
|------|------|
| Tenant Service | 租户管理、套餐、配额 |
| Auth Service | 权限鉴权、API Key |
| Scheduler Service | 任务调度、状态追踪 |
| Cost Tracker | 成本核算、账单 |
| Model Router | 模型选择、负载均衡 |

### 3. Python AI Service

| 模块 | 职责 |
|------|------|
| Agent Runtime | LangGraph Agent 编排 |
| RAG | 混合检索（Dense + BM25 + Reranker） |
| MCP | 工具标准化协议 |
| Skill | 业务能力封装 |
| Evaluation | RAG 评测 |

### 4. Observability

| 模块 | 职责 |
|------|------|
| Trace | 全链路追踪 |
| Metrics | Token/Cost/Latency 统计 |
| Logging | 日志收集 |
| Alert | 告警 |

## Java + Python 分工

| 层级 | 技术 | 职责 | 优势 |
|------|------|------|------|
| 控制平面 | Java (Spring Boot) | 租户、权限、调度、成本、路由 | 企业级能力、稳定性 |
| AI 服务 | Python (LangGraph) | Agent 编排、RAG、LLM 调用 | 快速迭代、AI 生态 |
| 可观测性 | OpenTelemetry + Prometheus | 追踪、指标、日志、告警 | 标准化 |

## 面试时的讲法

> "我设计了一个 Java + Python 混合架构的 Agent 平台。
>
> Java 控制平面负责租户管理、权限鉴权、任务调度、成本核算、模型路由——这些都是我 10 年 Java 经验的延伸。
>
> Python AI 服务负责 LLM 编排和 RAG。
>
> 关键设计：
> 1. 多租户隔离：数据、配额、性能、安全四个维度
> 2. 成本优化：根据任务复杂度路由到不同模型
> 3. 全链路追踪：每次请求都有完整 Trace
> 4. 异步处理：长任务通过 MQ 异步执行
>
> 这样既发挥了 Java 在企业级架构的优势，又用 Python 做 AI 编排。"
