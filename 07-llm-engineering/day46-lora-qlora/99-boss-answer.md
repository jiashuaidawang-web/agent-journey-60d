# Day 46 Boss 答案

## 1. 全量微调的问题？

- **参数量大**：7B、13B、70B 参数
- **显存占用高**：需要大量 GPU 显存
- **训练成本高**：时间和算力成本高
- **灾难性遗忘**：微调后可能遗忘原有知识

## 2. LoRA 的原理？

**核心思想**：
- 原始权重 W 冻结，不训练
- 引入低秩矩阵 A 和 B
- ΔW = A × B
- 新权重 = W + ΔW

**优势**：
- 只训练少量参数（<1%）
- 显存占用低
- 可插拔（不同任务不同 LoRA）

## 3. LoRA 和 QLoRA 的区别？

| 维度 | LoRA | QLoRA |
|------|------|-------|
| 基础模型精度 | FP16 | NF4 (4-bit) |
| LoRA 精度 | FP16 | BF16 |
| 显存占用 | 中 | 低 |
| 训练速度 | 快 | 较快 |
| 效果 | 好 | 接近 LoRA |
