# Day 37 Boss 答案

## 1. 多租户隔离的维度？

| 维度 | 说明 |
|------|------|
| 数据隔离 | 每个租户独立数据 |
| 配额隔离 | 每个租户独立配额 |
| 性能隔离 | 避免互相影响 |
| 安全隔离 | 权限控制 |

## 2. 数据隔离的方案？

| 方案 | 说明 | 适用 |
|------|------|------|
| 独立数据库 | 每个租户一个数据库 | 高隔离 |
| 共享数据库独立 Schema | 每个租户一个 Schema | 中隔离 |
| 共享表 + 租户 ID | 所有租户共享表 | 低隔离 |

## 3. 如何实现配额隔离？

1. **租户级配额**：每个租户独立配额
2. **配额检查**：每次请求前检查
3. **配额消耗**：记录使用量
4. **配额告警**：接近上限时告警
