# Day 29 Boss 答案

## 1. Router 和 Supervisor 的区别？

| 维度 | Router | Supervisor |
|------|--------|------------|
| 决策 | 单次路由 | 持续协调 |
| 交互 | 一对一 | 一对多 |
| 适用 | 多领域任务 | 复杂协作任务 |
| 复杂度 | 低 | 高 |

## 2. Router 如何决定路由？

1. **意图识别**：LLM 分析用户意图
2. **能力匹配**：匹配 Agent 的能力
3. **路由决策**：选择最合适的 Agent

## 3. 路由错误怎么办？

1. **置信度阈值**：低于阈值不路由
2. **澄清反问**：让用户确认意图
3. **Fallback**：默认 Agent 处理
4. **记录优化**：记录错误，持续优化
