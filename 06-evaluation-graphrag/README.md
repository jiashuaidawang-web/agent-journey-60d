## 为什么需要 GraphRAG？

**传统 RAG 的局限**：
- 基于块检索，无法捕捉全局关系
- 难以回答需要多跳推理的问题

**GraphRAG 的优势**：
- 实体关系建模
- 多跳推理能力
- 全局视角
