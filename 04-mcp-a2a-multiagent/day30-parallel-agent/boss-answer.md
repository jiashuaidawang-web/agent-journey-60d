# Day 30 Boss 答案

## 1. 什么任务适合并行？

- **无依赖**：任务之间互不影响
- **独立**：每个任务可以独立完成
- **多角度**：需要不同视角分析
- **搜索**：多个数据源同时搜索

## 2. 并行和串行的区别？

| 维度 | 并行 | 串行 |
|------|------|------|
| 执行方式 | 同时执行 | 依次执行 |
| 耗时 | 慢任务的时间 | 所有任务时间之和 |
| 依赖 | 无依赖 | 有依赖 |
| 资源 | 需要更多资源 | 资源少 |

## 3. 如何汇总并行结果？

1. **简单合并**：拼接所有结果
2. **投票**：多数决
3. **排序**：按置信度排序
4. **LLM 汇总**：用 LLM 总结
