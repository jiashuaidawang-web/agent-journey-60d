# GitHub提交标准

## Commit

推荐：

- feat: 新功能
- fix: Bug修复
- refactor: 重构
- test: 测试
- docs: 文档
- chore: 工程配置
- perf: 性能优化

## Issue

每个阶段至少创建：

- 学习Issue
- 实现Issue
- Bug Issue
- 复盘Issue

## Release

- v0.1.0：LLM基础Chat
- v0.2.0：Chat MVP
- v0.3.0：Tool Agent
- v1.0.0：M1 Final Release

## README必须包含

1. 项目介绍
2. 技术栈
3. 架构图
4. 快速启动
5. API
6. 配置
7. 数据库
8. Docker
9. 测试
10. 性能
11. 已知问题
12. Roadmap
