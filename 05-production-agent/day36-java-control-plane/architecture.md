## 模块说明

### 1. 租户管理（Tenant Service）

| 功能 | 说明 |
|------|------|
| 租户注册 | 创建租户，分配套餐 |
| 套餐管理 | basic / pro / enterprise |
| 配额管理 | Token、API 调用、存储配额 |
| 配额检查 | 每次请求前检查配额 |

### 2. 权限鉴权（Auth Service）

| 功能 | 说明 |
|------|------|
| 用户认证 | JWT / OAuth 2.0 |
| 权限控制 | RBAC（基于角色的访问控制） |
| API Key | 租户级 API Key |

### 3. 任务调度（Scheduler Service）

| 功能 | 说明 |
|------|------|
| 任务创建 | 接收请求，创建任务 |
| 任务分发 | 发送到 MQ |
| 状态追踪 | 追踪任务执行状态 |
| 结果存储 | 存储执行结果 |

### 4. 成本核算（Cost Tracker）

| 功能 | 说明 |
|------|------|
| 使用记录 | 记录每次 API 调用 |
| 成本计算 | 按模型、Token 计算成本 |
| 租户账单 | 按租户统计成本 |
| 成本优化 | 分析成本分布，优化建议 |

### 5. 模型路由（Model Router）

| 功能 | 说明 |
|------|------|
| 模型选择 | 根据成本/延迟/能力选择模型 |
| 负载均衡 | 多模型负载均衡 |
| 降级策略 | 主模型失败时降级 |

## Java + Python 分工

| 层级 | 技术 | 职责 |
|------|------|------|
| 控制平面 | Java (Spring Boot) | 租户、权限、调度、成本、路由 |
| AI 服务 | Python (LangGraph) | Agent 编排、RAG、LLM 调用 |

## 面试时的讲法

> "我设计了一个 Java + Python 混合架构。Java 控制平面负责租户管理、权限鉴权、任务调度、成本核算、模型路由——这些都是我 10 年 Java 经验的延伸。Python AI 服务负责 LLM 编排和 RAG。这样既发挥了 Java 在企业级架构的优势，又用 Python 做 AI 编排。"
