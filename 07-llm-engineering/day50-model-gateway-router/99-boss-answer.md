# Day 50 Boss 答案

## 1. 为什么需要模型路由？

- **成本优化**：不同任务使用不同价位的模型
- **性能优化**：根据延迟要求选择模型
- **能力匹配**：复杂任务用强模型，简单任务用弱模型
- **失败降级**：主模型失败时降级到备用模型

## 2. 路由策略有哪些？

| 策略 | 说明 |
|------|------|
| Cost-based | 根据成本选择最便宜的模型 |
| Latency-based | 根据延迟选择最快的模型 |
| Capability-based | 根据能力选择最合适的模型 |
| Hybrid | 混合策略，综合考虑 |

## 3. 如何实现失败降级？

1. **主模型失败**：自动切换到备用模型
2. **超时降级**：主模型超时时切换
3. **配额降级**：主模型配额用完时切换
4. **能力降级**：复杂任务降级到简单任务
