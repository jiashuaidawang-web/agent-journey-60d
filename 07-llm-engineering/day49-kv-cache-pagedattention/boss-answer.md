# Day 49 Boss 答案

## 1. KV Cache 的作用？

- **避免重复计算**：缓存已计算的 Key 和 Value
- **加速推理**：每步只计算新 token 的 KV
- **降低复杂度**：从 O(n²) 降到 O(n)

## 2. PagedAttention 的优势？

- **避免显存碎片**：分页管理，非连续存储
- **提高利用率**：从 20-40% 提升到 90%+
- **动态分配**：按需分配，灵活管理

## 3. Prefix Caching 的原理？

- 多个请求可能有相同前缀（如 System Prompt）
- 缓存前缀的 KV，避免重复计算
- 显著提高吞吐量
