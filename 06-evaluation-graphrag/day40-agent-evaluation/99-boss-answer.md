# Day 40 Boss 答案

## 1. Agent 评测的维度？

| 维度 | 指标 | 说明 |
|------|------|------|
| 任务完成 | Task Success Rate | 任务成功完成的比例 |
| 工具调用 | Tool Call Accuracy | 工具调用正确的比例 |
| 效率 | Steps to Completion | 完成任务所需步数 |
| 成本 | Token Usage | Token 消耗 |
| 安全 | Safety Score | 安全性评分 |

## 2. 如何评估任务完成率？

**方法**：
1. 构建评测数据集（任务 + 期望结果）
2. Agent 执行任务
3. 对比实际结果和期望结果
4. 计算成功率

**标准**：
- 完全成功：结果完全匹配
- 部分成功：结果部分匹配
- 失败：结果不匹配

## 3. 如何评估工具调用？

**评估维度**：
1. **工具选择**：是否选择了正确的工具
2. **参数正确**：参数是否正确
3. **调用顺序**：顺序是否合理
4. **结果利用**：是否正确利用了工具结果
