# Day 19 Boss 答案

## 1. BM25 的原理是什么？

**BM25（Best Matching 25）** 是基于词频的检索算法。

**公式**：
```
score(D, Q) = Σ IDF(qi) * (tf(qi, D) * (k1 + 1)) / (tf(qi, D) + k1 * (1 - b + b * |D| / avgdl))
```

其中：
- `qi`：查询中的第 i 个词
- `tf(qi, D)`：词 qi 在文档 D 中的频率
- `IDF(qi)`：逆文档频率
- `|D|`：文档长度
- `avgdl`：平均文档长度
- `k1, b`：调节参数

**核心思想**：
- 词频越高 → 分数越高（但有饱和）
- 罕见词（IDF 高）→ 更重要
- 长文档 → 惩罚

## 2. 为什么需要混合检索？

**单一检索的局限**：

| 检索方式 | 优势 | 局限 |
|----------|------|------|
| Dense | 理解语义 | 不擅长精确关键词 |
| Sparse (BM25) | 精确关键词 | 不理解语义 |

**混合检索的优势**：
- 兼顾语义和关键词
- 召回率更高
- 适用更多场景

**实际案例**：
```
查询："BGE-M3 嵌入模型"
Dense：可能匹配"向量嵌入"（语义相似）
BM25：精确匹配"BGE-M3"（关键词）
Hybrid：两者都召回
```

## 3. RRF 融合怎么计算？

**RRF（Reciprocal Rank Fusion）**：

公式：
```
score(doc) = Σ 1 / (k + rank_i(doc))
```

其中：
- `k`：平滑参数（通常 60）
- `rank_i(doc)`：文档在第 i 个列表中的排名

**示例**：
```
文档 A：Dense 排名 1，Sparse 排名 3
文档 B：Dense 排名 2，Sparse 排名 1

RRF(A) = 1/(60+1) + 1/(60+3) = 0.0164 + 0.0159 = 0.0323
RRF(B) = 1/(60+2) + 1/(60+1) = 0.0161 + 0.0164 = 0.0325

→ B 的分数更高（在两个列表中都排名靠前）
```

**优势**：
- 不需要分数归一化
- 简单有效
- 广泛应用
