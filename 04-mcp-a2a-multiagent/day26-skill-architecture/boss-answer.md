# Day 26 Boss 答案

## 1. Skill 层的作用是什么？

**Skill 层的核心作用**：

1. **业务封装**：将多个 Tool 组合成业务能力
2. **降低复杂度**：Agent 不需要知道 Tool 细节
3. **可复用**：同一个 Skill 可以在多个 Agent 中使用
4. **可维护**：业务逻辑集中在 Skill 层

**类比**：
- Tool = 螺丝刀、扳手（原子工具）
- Skill = 修理汽车（业务能力，使用多个工具）
- Agent = 技师（调用技能完成任务）

## 2. Skill 和 Tool 的区别？

| 维度 | Tool | Skill |
|------|------|-------|
| 粒度 | 原子操作 | 业务能力 |
| 例子 | HTTP 请求、数据库查询 | 行业研究、公司分析 |
| 调用者 | LLM 直接调用 | Agent 调用 |
| 内部 | 单一操作 | 调用多个 Tool |
| 复用性 | 高（跨业务） | 中（特定业务） |

## 3. 为什么 Agent 不直接调用 Tool？

**直接调用 Tool 的问题**：
1. **业务逻辑散落**：Agent 需要知道调用哪些 Tool、什么顺序
2. **耦合度高**：Tool 变化会影响 Agent
3. **难以复用**：业务逻辑绑定在 Agent 中

**引入 Skill 层的好处**：
1. **关注点分离**：Agent 关注决策，Skill 关注业务
2. **可插拔**：Skill 可以独立开发、测试、替换
3. **可扩展**：新增 Skill 不影响现有系统
